# ABANICADOS · versión mediterránea con intro animada

## Qué incluye
- Intro de entrada: el abanico se abre, aparece “Acá empieza el problema: elegir.” y luego se desplaza a la cabecera.
- Estética mediterránea/retro limpia: marfil, verde oliva, terracota y arena.
- Bordes marcados en las tarjetas, como en las versiones anteriores.
- Catálogo con filtros: TODOS, ESTAMPADOS, COLORES y PREMIUM.
- Fotos reales, precios, stock y ficha completa de cada abanico.
- Botón “LO QUIERO” por WhatsApp y “COMPARTIR ESTE MODELO”.
- Instagram, WhatsApp, materiales, funda, tamaño, pago y entrega.
